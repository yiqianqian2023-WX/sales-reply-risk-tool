# 业务员回复风险评估工具

## 一、项目背景

外贸平台每天会产生大量询盘、回复和跟进记录。仅靠人工逐条检查业务员是否及时回复、回复质量是否合格，成本高、效率低，也容易漏掉异常。

平台后台通常只能导出回复时间、客户信息、询盘内容、回复内容等原始 Excel 数据，无法直接输出适合管理层判断的业务员风险结果。

本工具通过上传平台导出的 Excel 表，自动完成回复时间风险分析、回复质量复核任务筛选，并结合人工复核打分，生成业务员回复风险评估结果。

## 二、项目定位

本工具不是 CRM，也不是自动处罚系统。

它的定位是：

- 回复时间风险分析工具
- 回复质量复核任务筛选工具
- 人工复核打分辅助工具
- 业务员接待风险评估工具

工具输出结果用于辅助管理判断。最终接待权限调整、业务员处理或处罚，应结合异常聊天内容抽查确认。

## 三、支持平台

当前项目支持两个平台：

1. 阿里国际站
2. 中国制造网

阿里国际站主要基于后台导出的回复明细、询盘中心报表等数据，分析业务员回复时间表现，并根据客户等级、国家、高意向、跟进状态等字段生成回复质量复核任务。

中国制造网主要基于后台导出的账户回复明细、Inbox / Sent 或询盘相关数据，分析 4 小时极速回复、24 小时及时回复等时间指标，并根据客户需求、业务员回复内容、强弱需求、占坑回复、重复模板、未回复等规则生成回复质量复核任务。

## 四、核心模块说明

### 1. 回复时间风险模型

回复时间风险模型用于分析业务员是否及时回复客户咨询。

当前支持：

- 阿里国际站回复时间风险
- 中国制造网回复时间风险

主要输出：

- 业务员接待风险汇总
- 异常明细
- 本周关键指标
- 分析结果 Excel 导出

主要指标包括：

- 总咨询数
- 极速回复数 / 极速回复率
- 人工极速数 / 人工极速率
- 非工作咨询数
- 非工作未极速数
- 超 1 小时数
- 超 4 小时未极速数
- 严重延迟数
- 异常记录占比
- 风险分

阿里国际站严重延迟标准按 6 小时计算。北京时间按原始发送时间 + 16 小时换算，回复时间按北京时间发送时间 + 回复时长小时反推。

中国制造网按 4 小时极速、24 小时及时规则判断。中国制造网回复时间风险读取真实回复明细，不读取账户统计、统计说明或汇总行。

### 2. 回复质量风险模型

回复质量风险模型用于从平台原始数据中筛选需要人工复核的商机任务。

当前支持：

- 阿里国际站回复质量风险模型
- 中国制造网回复质量风险模型

模型会输出 P0 / P1 / P2 / P3 复核优先级：

- P0 必须复核
- P1 优先复核
- P2 抽查复核
- P3 暂不重点

阿里国际站主要基于客户国家、客户等级、高意向、跟进状态、客户行为等字段生成复核优先级。

中国制造网主要基于客户原始需求、业务员回复内容、强弱需求、占坑回复、重复模板、未回复等规则生成复核优先级。

### 3. 人工复核模块

人工复核模块用于让管理人员查看商机和聊天内容后，对每条复核任务进行人工打分。

统一评分规则：

- 合格 = 0 分
- 轻微问题 = 1 分
- 一般问题 = 2 分
- 严重问题 = 3 分

风险分越高，代表该条商机的回复质量风险越高。

阿里国际站和中国制造网都应在回复质量风险模块内完成逐条人工复核打分。最终评估页面只做汇总，不作为某个平台单独的打分入口。

### 4. 最终风险评估模块

最终风险评估模块用于汇总各平台已完成的人工复核结果，并结合回复时间风险，按业务员输出最终风险结果。

主要输出：

- 业务员
- 复核商机数
- P0 / P1 / P2 / P3 结构
- 平均人工风险分
- 人工复核加权风险分
- 时间风险标准分
- 最终风险分
- 最终风险等级
- 风险提示 / 处理建议

最终评估页只负责汇总和最终评估，不承载单个平台的独立复核池。

## 五、数据流说明

整体数据流如下：

```text
上传平台 Excel 数据
→ 解析原始字段
→ 生成回复时间风险结果
→ 生成回复质量复核任务
→ 人工复核打分
→ 按业务员汇总
→ 计算最终风险分
→ 导出分析结果 Excel
```

## 六、关键规则说明

### 1. 回复时间风险规则

回复时间风险模型按平台分别计算。

阿里国际站：

- 严重延迟标准为 6 小时
- 北京时间 = 原始发送时间 + 16 小时
- 回复时间 = 北京发送时间 + 回复时长小时
- 异常明细只显示有风险标签的记录

中国制造网：

- 4 小时内回复视为极速
- 24 小时内回复视为及时
- 超 24 小时视为严重未及时
- 只读取真实明细数据，不读取账户统计、统计时间、账户统计汇总等行

### 2. 阿里国际站 P0 / P1 / P2 / P3 规则

阿里国际站回复质量模型主要参考客户国家、客户等级、高意向、跟进状态、历史行为、询盘信息等字段。

P0 / P1 用于进入默认重点复核范围，P2 用于抽查，P3 暂不重点。

当前特别规则：

- L0 客户不得进入 P0 或 P1
- P1 只允许 L1 及以上客户进入
- L0 命中强信号时最多进入 P2
- L0 没有明确需求或信息不完整时进入 P3

### 3. 中国制造网 P0 / P1 / P2 / P3 规则

中国制造网回复质量模型参考模板逻辑生成复核优先级。

主要判断因素包括：

- 客户原始需求
- 业务员回复内容
- 需求强度
- 疑似风险标签
- 建议动作
- 占坑回复
- 重复模板
- 未回复
- 是否回应核心需求

默认待复核列表只显示 P0 和 P1。P2 是抽查池，不默认计入必须复核数量。P3 默认隐藏，仅作为低优先级记录保留。

### 4. L0 客户处理规则

以下客户等级统一归一化为 L0：

- 空白
- -
- --
- N/A
- null
- undefined
- 未知
- 无

L0 规则：

- L0 默认进入 P2 或 P3
- L0 不允许进入 P1
- L0 不允许进入 P0
- L0 命中高意向、重点国家、明确需求、历史行为等信号时，最多进入 P2
- L0 信息不足或普通询盘时进入 P3

### 5. 高意向标签处理规则

高意向是平台标签，不是人工判断结果，也不代表客户一定高质量。

当前口径：

- 高意向只能作为辅助信号
- L0 客户不得仅凭高意向进入 P1
- 复核原因中使用“高意向辅助信号”这类描述
- 不使用“高意向强上调”作为默认文案

### 6. 人工复核评分规则

人工查看聊天内容后，对每条商机打分：

- 合格 = 0
- 轻微问题 = 1
- 一般问题 = 2
- 严重问题 = 3

单条风险分用于后续业务员维度汇总。

### 7. 最终风险分计算规则

最终风险分由两部分组成：

```text
最终风险分 =
时间风险标准分 × 40%
+ 人工复核加权风险分 × 60%
```

客户重要度不作为独立风险分单独相加，避免重复计算。

客户重要度只用于对人工复核结果进行加权：

- P0 权重 1.5
- P1 权重 1.2
- P2 权重 1.0
- P3 权重 0.8

单条加权风险分 = 单条人工风险分 × 复核优先级权重。

人工复核加权风险分 = 加权人工平均风险分 / 4.5 × 100。

4.5 是最高单条加权风险分，即 P0 严重问题 3 × 1.5。

### 8. 样本不足处理规则

复核商机数 = 0：

- 平均风险分显示 “-”
- 问题率显示 “-”
- 严重问题率显示 “-”
- 最终风险等级显示“无复核样本”
- 风险提示显示“本周期不评价”

复核商机数 > 0 且 < 5：

- 正常计算风险分
- 不进入正式低 / 中 / 高 / 严重风险评级
- 最终风险等级显示“样本不足，仅观察”

样本不足时：

- 如果严重问题数 >= 1，提示“有严重问题，需复查”
- 否则如果平均人工风险分 >= 1，提示“样本不足，需继续观察”
- 否则提示“仅观察”

复核商机数 >= 5：

- 正常进入正式风险等级判断

正式风险等级建议：

- 0-25：低风险
- 25-50：中风险
- 50-75：高风险
- 75-100：严重风险

## 十、开发注意事项

后续修改时需要注意：

- 不要随意重构现有单文件结构
- 不要修改已稳定的回复时间风险模型
- 不要随意扩大 P0 / P1 复核范围
- 不要把 P2 默认纳入必须复核
- 不要让最终评估页承载单独平台的打分池
- 修改前应先说明涉及函数和修改方案
- 每次修改后应测试阿里和中国制造网两个平台的数据是否正常
- 修改中国制造网回复时间风险时，要确保只读取真实回复明细，不读取账户统计或汇总行
- 修改中国制造网回复质量模型时，要以 Excel 模板为规则来源
- 修改阿里国际站回复质量模型时，要特别注意 L0 客户不能进入 P1
